# Tasks Alarm & Streak Challenge 🚀

تطبيق إدارة المهام والمنبهات مع نظام **Streak Challenge** محفز، مصمم لتطبيق Flutter بدعم مخصص لـ **Android 13** و **Windows 11**.

## المميزات ✨
- **Streak System 🔥:** تتبع إنجاز المهام اليومية بدون انقطاع لزيادة التحدي.
- **UI عصري ✨:** تصميم متجاوب يعتمد على Material 3 مع أنيماسيون سلس.
- **دعم Android 13 📱:** توافق كامل مع تصريحات المنبهات والتنبيهات الدقيقة (`SCHEDULE_EXACT_ALARM` و `POST_NOTIFICATIONS`).
- **دعم Windows 11 💻:** مخصص للعمل على سطح المكتب مع نظام Tray Icon.

## التشغيل 🛠️
```bash
flutter pub get
flutter run
```
